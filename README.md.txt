# MEI Fácil IA

App para freelancers e MEIs organizarem finanças com ajuda de IA (Gemini).

## Como usar

### Opção 1 – GitHub Pages (recomendado)
1. Suba esta pasta no GitHub
2. Ative o GitHub Pages (Settings → Pages → Deploy from branch main)
3. Acesse o link HTTPS que o GitHub gerar
4. A câmera e todos os botões funcionam normalmente

### Opção 2 – Abrir direto no celular
- No Android: use o app "Web Server" ou "HTTP Server" e abra pelo navegador em `http://localhost:...`
- Abrir o arquivo `index.html` direto (file://) **pode bloquear a câmera** e alguns recursos.

## Configurar a IA real
1. Abra o app
2. Vá em **Conta**
3. Cole sua chave do Gemini
4. Clique em **Salvar chave**

A chave fica salva somente no seu navegador.

## Funcionalidades
- Dashboard com receitas, despesas e estimativa de DAS
- Tirar foto ou escolher da galeria
- IA real (Gemini) ou simulação
- Relatórios por categoria
- Exportação CSV
